INTELLICHECK — QUICK START

1. Extract this ZIP.
2. Open the extracted IntelliCheck_Full_Project folder in VS Code.
3. Double-click Run-IntelliCheck.bat.
4. Open http://localhost:8080 in Edge or Chrome.
5. Keep the black terminal window open while using the website.
